Leonida Legend is an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI. Every trophy is shown with its official name, description and grade, a guide written in our own words with its sources cited beside it, and the steps to earn it. The tracker saves progress in the browser (localStorage), exports it to a file and imports it back, filters by kind (story, missable, collectibles, activities, online), and has a spoiler setting that hides story trophies until they are earned. A five-stage roadmap leads to the platinum, and the one missable trophy is flagged with exactly how to avoid missing it. Runs entirely offline from its own static files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network at runtime.
